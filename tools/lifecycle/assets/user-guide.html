How to use PowerCodex

PowerCodex turns a plain-language goal and a first-slice MVP into a running, continuously-verified app — and it never touches your tenant without permission. This guide explains the screen you're looking at and how to drive it.

Two ways to drive it — same engine

Pick whichever feels comfortable. They control the exact same lifecycle underneath, so you can switch anytime.

🪟 Studio — this dashboard

A guided, click-through screen. Everything is a button, and the stepper at the top keeps you oriented. Best if you'd rather not use a terminal.

⌨️ Cockpit — the terminal

A real terminal you talk to directly. Run npm run cockpit. Type a request, or / for commands. Faster once you know it.

The screen flow — five steps

The Studio walks the lifecycle left-to-right. The stepper shows where you are; it lights up the live stage as the loop runs. Click any step to look around, or press following live to snap back to whatever the loop is doing now.

STEP 1

Goal & MVP

Type what the app should do and the first slice to build. Set the goal↔MVP compliance, then Save intake.

STEP 2

Plan & approve

Review the HTML plan the agent generated before anything builds. When it looks right, press Approve.

STEP 3

Build & run

Press ▶ Start loop and watch it work: the 7-stage strip, the agents, and the live activity feed all stream here.

STEP 4

Test & observe

See MVP coverage and any specs the observer wrote from what it noticed during the run.

STEP 5

Insights & lessons

Is the loop improving each rotation? Review insights and the lessons it has learned. Reflect to add your own.

▶ Your first run, start to finish

  1. Step 1 · Describe it.

    On Goal & MVP, fill the goal and MVP boxes and press Save intake. The context bar at the top now shows them, with a compliance meter.

  2. Grant the rights you're comfortable with.

    In that top context bar, the chips build / push / auto-respec / auto-fix are the consent gate. Click one to toggle it. Everything is off until you say so.

  3. Step 3 · Start the loop.

    Go to Build & run and press ▶ Start loop. The stepper follows along as it builds, runs, and tests — newest events stream into the activity feed.

  4. Steps 4–5 · Check the result.

    When it settles, Test & observe shows coverage and any new specs; Insights & lessons shows whether it's getting better. The status pill (top-left) reads complete ✓ when it's green.

The consent gate — why it sometimes stops

PowerCodex will never build on or push to your tenant without permission. If the loop stops with a warning, it's almost always a right that's switched off.

⚠️
"Loop stopped"? Check the rights chips in the context bar. If you meant to allow it, toggle build (to create on the tenant) or push (to ship the app) on, then press ▶ Start loop again.

Prefer the terminal? Cockpit commands

Run npm run cockpit. Type a request to talk to your AI, or press / and Tab to autocomplete a command. ↑/↓ recalls history; Ctrl-C interrupts a reply.

CommandDoes
/providerSwitch the AI — Claude Code, GitHub Copilot, or the built-in fallback.
/start · /statusRun the lifecycle loop · show the goal / MVP / rights / rotation snapshot.
/rights build onToggle a consent flag (same gate as the Studio chips).
/plan open · /plan listOpen the latest generated plan in your browser · list them all.
/studioOpen this graphical dashboard in a browser.
/help · /quitList every command · leave the cockpit.

Still stuck?

  • Nothing is moving? The loop only runs when you press ▶ Start loop (Step 3) — or it finished. Press ↺ Reset and start again.
  • Lost your place? Press following live in the Lifecycle-flow bar to jump to whatever the loop is doing now.
  • "Lost connection"? The dashboard server stopped. Restart it with npm run lifecycle:serve -- --open.
  • Want to see it move first? Run npm run lifecycle:serve -- --demo for a paced simulated loop.
