Change — a real, honest Engine 1

Now

  • buildExecutor() is fully simulated: for each task it just emits "X created (simulated)".
  • Nothing opens a browser; Power Platform is never touched.
  • No mapping from a task contract to where it lives in the maker portal.

New

  • New lib/maker-recipes.js maps each task type → the real maker surface URL (Dataverse tables/columns/connections on make.powerapps.com, flows on make.powerautomate.com), env-scoped when you supply one.
  • Real buildExecutor in lib/engines.real.js: attach → for each task, navigate into the maker surface and verify it loaded.
  • Reports the truth: "reached the Tables surface · field-by-field creation not yet automated (front-end pending)", with created:false, automated:false. It never claims to have created an asset it didn't.
  • Gated by Approved_rights/ allowBuild — entering the portal is a real tenant action.

Per-task behavior (real mode)

for task in tasks:
  url = makerRecipe(task.type).url(env) # e.g. make.powerapps.com/environments/<env>/tables
  nav = runAppSmokeTest(context, url) # REAL: open the surface, confirm it loaded
  emit "reached Tables surface · creation step not yet automated"
  result = { status:"navigated", created:false, automated:false }

What you'll run

npm i -D playwright
npm run lifecycle -- loop --real --app-url https://<your-app> [--env <environmentId>]

With --real + Playwright + granted allowBuild, the loop attaches to your managed Edge and opens each maker surface in turn. Supply --env to land directly in your environment's Tables/Flows list; without it, it enters the portal home and your default environment.
