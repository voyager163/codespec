What it is

Requirements that live in the repo, not in chat history

Most AI tools help you write code, then forget why. PowerCodex keeps the project's intent next to the code — as files you can review, change, implement, verify, and archive — and wraps the whole build in one observable loop. Ideas become specs, specs become a running app, and the app keeps proving it still meets the goal.

📐

Spec-driven, by default

An OpenSpec config tuned for Code Apps and 11 OPSX prompt + skill files turn ideas into reviewable proposals, designs, and tasks.

🔁

Autonomous, not blind

The loop runs on its own but stops at a real consent gate before anything touches your tenant. It only does what you turned on.

🩹

Self-healing

When a test goes red, the e2e engine diagnoses it, authors a spec from the observation, and re-builds — and you watch it happen.

The loop

Seven stages, one rotation

Each rotation moves through seven stages. The dashboard highlights the current stage live; when a rotation ends, observations feed the next one — defects, gaps, and improvements become the next plan.

The Approve stage is a real gate, not a formality. PowerCodex reads Approved_rights/ before it builds or pushes. If the relevant flag (build / push / auto-respec / auto-fix) is false, the loop blocks right there and waits for you.

Quick start

Three commands to a project, two to watch it run

PowerCodex is an npm initializer plus a small zero-dependency lifecycle tool. Scaffold a project, then open the dashboard and drive the loop.

1 · Scaffold the project

# global install
npm install -g @voyager163/powercodex@latest
powercodex my-app
cd my-app && code .

# or without installing
npx @voyager163/powercodex my-app

2 · Initialize for your tenant

# Power Platform CLI
pac code init --environment <id> \
  --displayName <appName>

# start local development
npm run dev

3 · Open the dashboard, then run the loop

npm run lifecycle:serve              # http://localhost:4321 — keep it open
npm run lifecycle -- loop             # run the loop; the dashboard follows live
npm run lifecycle:selftest           # run the product against itself (16/16 checks)
Already have an app? npm run lifecycle -- import --analyze reads your existing routes, components, and data calls into a digest, then derives user stories and an MVP grounded in your real code — so the same loop can run the rest of that project.
